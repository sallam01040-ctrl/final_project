# Student Performance Diagnostics — Next.js Frontend

Production frontend web interface built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**.

---

## Highlights

- **Impeccable Craft**: High-contrast, tabular numerals, restrained academic color palette, responsive design.
- **Zero AI Icons**: Strictly academic, statistical, and analytical iconography.
- **English-Only Interface**: Clean, professional terminology tailored for educators and students.
- **Standalone Engine**: Runs client-side or serverless with exact model weights, with optional forwarding to FastAPI backend via `NEXT_PUBLIC_API_URL`.

---

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

---

## Build & Vercel Deployment

```bash
npm run build
```

Deploy directly by importing this directory into Vercel.
